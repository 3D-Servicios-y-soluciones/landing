    Qué mirar cada semana

    • Clics en WhatsApp Es tu métrica de leads, no las visitas. Una página con muchas visitas y cero clics tiene un problema de mensaje, no de tráfico.
    • Qué página los genera Si las páginas por segmento convierten mejor que el inicio, conviene invertir ahí y crear más.
    • Configurador completado vs. iniciado Si mucha gente parte y pocos terminan, el paso donde abandonan está pidiendo algo que no saben responder.
    • De dónde llegan Búsqueda, directo o Perfil de Empresa. Para un servicio local el perfil de Google suele traer más que el sitio.

    Pendientes del sitio

    • Testimonios Dos o tres, con nombre, cargo, empresa y autorización.
    • Cifras respaldables Años, m² bajo contrato, dotación, clientes activos.
    • Certificaciones OS-10, mutualidad, trabajo en altura.
    • Fotos antes / después Pares del mismo encuadre, para el deslizador.
    • Promesa de respuesta Un plazo que se pueda cumplir siempre.

    Cómo se protege esta página

    El sitio es estático: se sirve desde GitHub Pages, sin servidor propio. Eso significa que una contraseña escrita en el código sería visible para cualquiera que abra «ver código fuente». Por eso aquí no hay ninguna.

    La protección de verdad va antes, en Cloudflare, que ya está delante de tu dominio. Cloudflare pide un código de acceso antes siquiera de servir esta página. Es gratis hasta 50 usuarios.

    No hace falta configurarlo a mano: el repositorio incluye el flujo «Proteger /admin con Cloudflare Access» en la pestaña Actions de GitHub. Agrega una vez los secretos CLOUDFLARE_API_TOKEN y CLOUDFLARE_ACCOUNT_ID, ejecútalo, y queda cerrado. Es reejecutable: sirve también para cambiar quién tiene acceso.

    Si prefieres hacerlo por pantalla: Zero Trust → Access → Aplicaciones, agrega una aplicación autoalojada para www.3dgroup.cl/admin y una política que permita sólo tu correo.

    Mientras tanto: esta página no está en el sitemap, lleva noindex y está bloqueada en robots.txt, así que no aparecerá en buscadores. Y no guarda ningún dato — sólo muestra tableros que llevan su propia autenticación.
